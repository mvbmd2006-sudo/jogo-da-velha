🎮 Jogo da Velha 3x3

📌 Sobre o projeto

Este projeto consiste no desenvolvimento de um jogo da velha 3x3 utilizando Python, no qual dois jogadores se enfrentam com o objetivo de formar uma sequência de três símbolos iguais na horizontal, vertical ou diagonal.

O projeto também possui um sistema de estatísticas da sessão, que registra os resultados e acompanha o desempenho dos jogadores.

👥 Integrantes e responsabilidades

* Elias: desenvolvimento do menu principal, navegação e regras do jogo.
* Marcos: desenvolvimento do tabuleiro, jogadas, validações e verificação de vitórias e empates.
* Rodrigo: implementação das estatísticas, placar, percentuais de vitórias e controle de sequências.

🛠️ Tecnologias utilizadas

* Python 3
* Visual Studio Code
* Git e GitHub

📊 Funcionalidades

* Tabuleiro de jogo da velha 3x3.
* Partidas entre dois jogadores (X e O).
* Identificação automática de vitórias e empates.
* Validação das posições escolhidas.
* Contagem de vitórias de cada jogador.
* Registro do total de partidas.
* Cálculo do percentual de vitórias.
* Controle da maior sequência de vitórias.
* Placar atualizado durante a sessão.

▶️ Como executar

1. Instale o Python 3 no computador.
2. Clone ou baixe este repositório.
3. Abra a pasta do projeto no Visual Studio Code.
4. Execute o arquivo principal jogo_da_velha.py.
